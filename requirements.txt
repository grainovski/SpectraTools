# 6.11.x fails with "DLL load failed while importing QtWidgets" on Windows
# Also: every PySide6 wheel from 6.3.0 onward requires glibc >=2.28 (the
# last version with an older/manylinux1 wheel was 6.2.4, from 2021) --
# this is why SpectraTools doesn't run on RHEL/CentOS 7 (glibc 2.17), and
# no Linux build-baseline choice can work around it. See
# packaging/linux/INSTALL.md and docs/superpowers/specs/2026-08-03-linux-native-packages-design.md.
PySide6>=6.6,<6.9
# Upper bound is deliberate, matching PySide6's above: theme.py's
# refresh_builtin_toolbar_icons() drives NavigationToolbar2QT._icon(), a
# PRIVATE matplotlib API, to recolor the built-in Save/Home/Pan icons on a
# theme toggle. A matplotlib release that renames or removes that method
# would silently reintroduce the icon-theming bug it was written to fix,
# and no test asserts icon color. Verified working on 3.10.x and 3.11.x --
# raise the ceiling only after re-checking that path by hand.
matplotlib>=3.8,<3.12
numpy>=1.26
scipy>=1.11
